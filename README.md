# 🛡️ FatalToolbox

**Uma coleção open source de ferramentas e scripts para admins de servidores.**

Ideal para servidores de jogos como Minecraft, Metin2, FiveM, SA-MP e outros ambientes que precisam de automação e estabilidade.

## ⚙️ O que tem aqui?
- Scripts bash e python prontos para uso
- Automação de backups, limpeza de cache, instalação de plugins
- Painel Web (HTML5) com status e comandos básicos
- Exemplos de configs otimizadas (Nginx, Docker, etc)

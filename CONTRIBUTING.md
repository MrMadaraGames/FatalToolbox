# Como Contribuir com o FatalToolbox

Seja bem-vindo! Este projeto é aberto para todo tipo de contribuição:
- Scripts em qualquer linguagem
- Sugestões de melhoria
- Traduções
- Melhorias no painel web
- Correções e otimizações

## Regras básicas
- Crie scripts limpos e comentados
- Use nomes de arquivos simples e claros
- Teste localmente antes de enviar
